# 食算 — 工厂食品成本换算工具

> 专为食品工厂一线人员设计：把实验室小批量成本，逐级换算成吨价、箱价、包价，
> 并进一步给出毛利报价与损耗洞察。
> 核心计算由 **Rust 引擎**（libshisuan_core.so）通过 JNI 在设备本地执行，完全离线。

## 核心功能

- **产品工作流**：新建产品 → 产品详情 → 为产品新建批次（含配料明细）
- **成本换算链路**：实验室小样成本 → 克单价 → 吨价（×1,000,000）→ 箱价 → 包价
- **加工费核算**：包材 / 人工 / 水电折旧分项录入，与原料成本合并为真实总成本
- **出品率折算**：投料重量 × 出品率 = 有效产量，避免熬煮损耗导致吨价被低估
- **毛利报价**：产品级目标毛利率 → 批次卡直接给出建议出厂价（元/吨）
- **配料明细**：每个批次记录原料用量×单价，自动汇总原料成本
- **原料库**：跨产品复用的原料档案（名称+品牌去重、使用频次排序、库存单价）
- **成本差异对比**：同产品批次间自动标注涨跌幅（↑/↓ 百分比）
- **成本趋势 / 配料占比**：自绘折线图与环形图，看走势、找降本重点
- **损耗分析**：平均/最近出品率、损耗对吨价的抬升、恢复到历史最佳的潜在节省
- **批次成果记录**：口感/颜色/pH/糖度/评分随批次留存，成本与品质一起看
- **配方复制**：以已有批次为模板一键新建，只改差异项，适合试产迭代
- **版本快照链**：批次每次变更自动存档（SHA-256 内容指纹），可回溯可恢复
- **OCR 识别**：拍照/选图识别配料表文字，批量入库
- **数据备份与恢复**：SAF 导出/导入 SQLite 备份，含完整性校验与原子替换
- **快捷输入**：± 步进按钮、滑条选择、常用值标签（g/kg/%/元等），减少文字录入
- **物理动效**：按压弹簧回弹、卡片错峰弹性入场

## 技术栈

- Kotlin + Jetpack Compose（UI 层）
- **Rust 计算引擎**（`shisuan-rs/` → libshisuan_core.so，经 JNI 调用）
- Room（本地数据库，完全离线，迁移链 v1→v11）
- Navigation Compose + Hilt（依赖注入）
- MVVM + Repository 架构
- ML Kit 中文 OCR（离线模型）
- R8/ProGuard + GitHub Actions 自动构建发布

## 架构

```text
┌────────────────────────────────────────────────┐
│ Compose UI（产品列表 → 详情 → 新建/编辑批次）   │
│   CostCalculator.kt ──委托──▶ ShisuanCore (JNI) │
└───────────────────────┬────────────────────────┘
                        │ JNI (external fun)
┌───────────────────────▼────────────────────────┐
│ Rust 引擎 libshisuan_core.so（shisuan-rs/）     │
│   成本换算 · 差异对比 · 单价换算 · 四舍五入      │
└────────────────────────────────────────────────┘
```

Rust 引擎源码、接口说明与交叉编译方法见 [shisuan-rs/README.md](shisuan-rs/README.md)。

## 数据模型

| 实体 | 说明 |
|------|------|
| Product | 产品（草莓酱/蓝莓酱…），含包装规格与目标毛利率 |
| BatchRecord | 批次记录（投料重量、加工费分项、出品率，关联产品） |
| BatchIngredient | 批次配料明细（用量×单价→小计） |
| Ingredient | 原料档案（品牌/分类/库存单价/保质期等特性） |
| BatchResult | 批次成果（口感/颜色/pH/糖度/评分，详情页可录入） |
| BatchSnapshot | 版本快照（SHA-256 内容指纹，可回溯历史版本） |
| OperationLog | 操作日志（审计追踪，自动裁剪保留最新 500 条） |

## 构建

CI 会在推送到 `main` 时自动运行单测、构建 debug 包并发布
`debug-latest` 预发布；`v*` 标签触发签名 release 构建。本地构建方式：

```bash
# 1. （可选）重新编译 Rust 引擎到 jniLibs
cd shisuan-rs && ./build-android.sh && cd ..

# 2. 构建 APK
./gradlew assembleDebug
# APK 输出: app/build/outputs/apk/debug/app-debug.apk
```
