# 新业务流程设计

## 核心流程
1. **产品管理** (主页)
   - 产品列表：显示所有产品（草莓酱、蓝莓酱等）
   - 点击产品 → 进入产品详情
   - FAB 新建产品

2. **产品详情页**
   - 显示该产品的所有批次
   - 批次卡片显示成本计算结果
   - FAB 新建批次（配料）

3. **新建批次页**
   - 批次编号、样品重量
   - **原料配料列表**（可添加多个原料）
     - 原料名称、用量(g)、单价(元)
   - 加工费
   - 自动计算总成本 = Σ(原料用量 × 单价) + 加工费
   - 保存后关联到当前产品

## 数据模型调整
- Product (产品表) - 新增
- BatchRecord (批次表) - 修改：添加 productId，移除 materialCost
- BatchIngredient (批次原料明细表) - 新增
- Ingredient (原料库) - 保持
